INVENTORY MANAGEMENT SYSTEM

Developed By: Mitali Dange

---

1. Project Introduction

The Inventory Management System is a Python-based desktop application developed to manage and maintain inventory-related activities efficiently.

This application provides a graphical user interface (GUI) that helps users manage employees, suppliers, product categories, products, billing, and sales records.

The system uses SQLite database to store and manage information securely and efficiently.

2. Project Objectives

- To manage inventory records efficiently.
- To maintain employee and supplier information.
- To manage product details and categories.
- To simplify the billing process.
- To maintain sales and invoice records.
- To reduce manual paperwork and save time.

3. Technologies Used

Technology| Purpose
Python| Backend Programming
Tkinter| Graphical User Interface
SQLite3| Database Management
Pillow (PIL)| Image Processing
VS Code| Development Environment

4. Main Features

1. Dashboard

- User-friendly dashboard.
- Displays inventory management options.
- Provides access to different modules.

2. Employee Management

- Add new employees.
- Update employee details.
- Delete employee records.
- Search employees by name, email, or contact.

3. Supplier Management

- Add supplier details.
- Update supplier information.
- Delete supplier records.
- Search suppliers using invoice number.

4. Category Management

- Add product categories.
- Delete existing categories.
- Manage product classification.

5. Product Management

- Add new products.
- Update product information.
- Delete products.
- Search products by name, category, or supplier.
- Check product availability.

6. Billing Management

- Generate customer bills.
- Display product details and prices.
- Calculate total billing amounts.
- Apply discounts.
- Save generated bills.

7. Sales Management

- View sales records.
- Search bills using invoice numbers.
- Maintain billing history.

5. Project Modules

The project contains the following Python files:

File Name| Description
dashboard.py| Main dashboard
employee.py| Employee management
supplier.py| Supplier management
category.py| Category management
product.py| Product management
billing.py| Billing operations
sales.py| Sales records
create_db.py| Database creation

6. Software Requirements

- Operating System: Windows 10 / Windows 11
- Python 3.x
- Visual Studio Code
- SQLite3
- Pillow Library

7. Installation and Setup

Step 1: Install Python

Download and install Python from:

https://www.python.org/downloads/

Step 2: Install Visual Studio Code

Download VS Code from:

https://code.visualstudio.com/

Step 3: Extract the Project

Extract the downloaded project ZIP file and open the project folder in VS Code.

Step 4: Install Required Library

Open the VS Code terminal and execute:

py -m pip install pillow

Step 5: Create Required Folders

Make sure the project contains the following folders:

- images
- bill

The images folder contains project images, and generated bills are saved in the bill folder.

8. How to Run the Project

Follow these steps to execute the project:

Step 1: Open the project folder in Visual Studio Code.

Step 2: Open the terminal.

Step 3: Create the database by running:

py create_db.py

Step 4: Start the main dashboard:

py dashboard.py

Step 5: Use the dashboard to access Employee, Supplier, Category, Products, and Sales modules.

Step 6: Run the billing module when required:

py billing.py

9. Database Information

The project uses SQLite3 as its database management system.

The database is created using the "create_db.py" file.

It stores information related to the inventory management operations and helps retrieve and update records.

10. Advantages of the Project

- Easy to use graphical interface.
- Efficient inventory record management.
- Faster billing operations.
- Easy employee and supplier management.
- Organized product information.
- Reduced manual work.

11. Conclusion

The Inventory Management System is designed to make inventory-related tasks easier, faster, and more organized.

It provides different modules for managing employees, suppliers, products, categories, billing, and sales.

This project demonstrates the practical implementation of Python programming, Tkinter GUI, and SQLite database management.
